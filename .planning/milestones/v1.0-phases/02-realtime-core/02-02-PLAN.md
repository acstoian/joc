## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser client → Supabase Realtime (anon key) | The hook holds the WebSocket using the anon key only; no privileged credential is reachable client-side |
| received GAME_EVENT payload → hook state | Broadcast payloads are attacker-shaped data arriving over the channel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | GAME_EVENT broadcast payload trusted as state | mitigate | D-06 — the hook NEVER reads game data off the event payload; every event triggers a re-fetch of `GET /api/game/state` (the DB is the single source of truth), so a forged/replayed/out-of-order broadcast cannot corrupt displayed state |
| T-02-06 | Elevation of Privilege | service-role key in client bundle | mitigate | The hook imports only `createClient` (anon key, NEXT_PUBLIC_ only); it never imports `@/lib/supabase/admin`; `grep service_role` in the hook returns 0 |
| T-02-07 | Denial of Service | presence flooding at 100+ clients | mitigate | `channel.track()` called exactly once per connection in the SUBSCRIBED branch — never in render/broadcast paths (D-04/D-09, Pitfall 3) |
| T-02-SC | Tampering | npm installs | accept | No new packages this phase (RESEARCH Package Legitimacy Audit vacuous) |
</threat_model>
