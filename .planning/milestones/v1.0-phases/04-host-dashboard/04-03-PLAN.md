<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → /api/host/questions* | Untrusted input crosses here; must validate auth + UUIDs + body |
| Question routes → questions base table | Service-role bypasses RLS; must not expose correct_option to guests via public surfaces |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07 | Elevation of Privilege | all /api/host/questions* handlers | mitigate | validateHostAuth(req) is the first statement of every handler; 401 before any DB access. |
| T-04-08 | Denial of Service | DELETE active question mid-game | mitigate | Read games.current_question_id and 409 with Romanian error if it matches the id being deleted (Pitfall 4). |
| T-04-09 | Information Disclosure | correct_option leak | mitigate | Host routes use adminClient.from("questions") server-side only; the public read path keeps using questions_public; adminClient is import "server-only" (Pitfall 6 prevents client import). |
| T-04-10 | Input Validation | malformed gameId / order / body | mitigate | UUID_REGEX validation on gameId and every reorder id; non-empty string checks on body/option_a/option_b → 400 (ASVS V5). |
| T-04-11 | Tampering | parallel reorder requests | accept | Reorder writes exact display_order values (idempotent, last-writer-wins); acceptable for a single host (RESEARCH Security Domain). |
</threat_model>
