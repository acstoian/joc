## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → /api/host/answers | Untrusted; must auth + validate UUIDs before exposing player names |
| answers/players join → response | Player names are sensitive (who picked what); must not reach guests/TV |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-12 | Information Disclosure | /api/host/answers names | mitigate | Endpoint is host-auth-gated (validateHostAuth first statement); names are NEVER added to public GET /api/game/state, so guests/TV cannot discover who picked what (RQ-1). |
| T-04-13 | Elevation of Privilege | answers endpoint | mitigate | 401 before any DB access; same pattern as all Phase 3 host routes. |
| T-04-14 | Input Validation | gameId/questionId params | mitigate | UUID_REGEX validation → 400 on malformed (ASVS V5). |
</threat_model>
