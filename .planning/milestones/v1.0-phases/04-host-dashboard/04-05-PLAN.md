## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Emergency panel → /api/host/* | Untrusted client; server re-validates auth on every emergency action |
| force_end action → games table | Privileged phase mutation from any state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-15 | Elevation of Privilege | force_end / reset / jump | mitigate | All go through hostFetch with x-host-password; transition + reset routes call validateHostAuth first (reset is Phase 3; force_end gated in Task 1). |
| T-04-16 | Tampering | force_end racing a normal transition | mitigate | force_end uses a CAS-style `.neq("phase","ended")` guard; concurrent transitions converge — 0 rows → idempotent noop, never corrupts state. |
| T-04-17 | Denial of Service | accidental destructive action | mitigate | Reset + force-end require AlertDialog confirmation; emergency panel is collapsed-by-default and visually subdued (UI-SPEC §5.3 C). |
</threat_model>
