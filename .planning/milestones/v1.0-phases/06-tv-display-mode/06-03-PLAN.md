## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host client → POST /api/host/countdown | The countdown button sends gameId + seconds; the endpoint (06-01) validates host auth and clamps seconds |
| Supabase Broadcast (COUNTDOWN_STARTED) → display | The display reacts to the event type only (via onEvent) to set a local countdown; no game data is read off the payload |
| leaderboard names → winner DOM | Winner name + leaderboard names are rendered as text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Spoofing | POST /api/host/countdown (triggered by this button) | mitigate | Endpoint validates host auth (06-01); the button sends the password via hostFetch — an unauthenticated caller is rejected 401 |
| T-06-02 | Tampering | countdown seconds | mitigate | Button hard-codes `seconds: 3`; endpoint independently clamps to 1-10 (06-01) so even a forged call cannot set a multi-minute overlay |
| T-06-04 | Tampering | winner name + leaderboard text in WinnerDisplay | mitigate | Rendered as React text nodes; no `dangerouslySetInnerHTML` — XSS-safe |
| T-06-06 | Denial of Service | repeated countdown clicks | mitigate | `countdownInFlight` + `anyInFlight` disable the button for 2s and during transitions, throttling broadcast spam |
| T-06-SC | Tampering | npm installs | mitigate | No new packages — reuses lucide-react Trophy + existing LeaderboardPanel |
</threat_model>
