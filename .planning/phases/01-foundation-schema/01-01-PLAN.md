## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Next.js client bundle -> Supabase | Anon key + RLS is the only credential that may reach the browser. Service-role key and HOST_PASSWORD must never cross into client code. |
| Server (API routes / server modules) -> Supabase | service_role key used server-only for privileged writes + REST broadcast. |
| Repo working tree -> git | D-04: assistant makes no commits; secrets live only in gitignored `.env.local`. |
