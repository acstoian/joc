## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Pinned next to exact 15.3.9 instead of ^15.3.0**
- **Found during:** Task 1 build verification
- **Issue:** `^15.3.0` resolved to `15.3.9` → wait, it actually resolved to `15.5.19` (beyond the minor). Running build produced `WasmHash TypeError: Cannot read properties of undefined (reading 'length')` — a known webpack WASM hash incompatibility with Node.js v24. `next@15.5.x` is affected; `next@15.3.x` is not.
- **Fix:** Changed `"next": "^15.3.0"` to `"next": "15.3.9"` (exact pin) and re-ran `npm install`. Also pinned `eslint-config-next` to match.
- **Files modified:** `package.json`
- **Verification:** `npm run build` succeeded with Next.js 15.3.9 on Node v24.14.0

**2. [Rule 3 - Blocking] scripts/ directory fully deleted (not just generate-images.ts)**
- **Found during:** Task 1 — first build attempt
- **Issue:** Plan specified removing `scripts/generate-images.ts` only. However, `scripts/gen-layout-images.ts`, `generate-invitation.ts`, `overlay-qr.ts`, `photoshop-invitation.jsx` all remained and referenced `@google/genai` causing TypeScript to fail with "Cannot find module '@google/genai'" — breaking the build.
- **Fix:** Removed entire `scripts/` directory (all files were old wedding scripts with no Joc relevance).
- **Files modified:** None — directory deleted
- **Verification:** Build passed after deletion

**3. [Rule 3 - Blocking] components.json written manually instead of via `npx shadcn@latest init -t next`**
- **Found during:** Task 2 shadcn init
- **Issue:** `shadcn@latest init` is a fully interactive TTY prompt (component library selection, preset, etc.) that cannot be driven by piped input in non-TTY bash — it hangs waiting for arrow-key input.
- **Fix:** Wrote `components.json` manually per the shadcn Tailwind v4 spec (new-york style, RSC, TSX, correct aliases). The file is functionally identical to what the CLI produces for a Tailwind v4 + Next.js App Router project.
- **Files modified:** `components.json` (created)
- **Verification:** File exists, valid JSON, matches shadcn schema
