The body performs ONE statement: `INSERT INTO scores (player_id, correct_count, updated_at) SELECT p.id, COUNT(a.id) FILTER (WHERE q.correct_option IS NOT NULL AND a.choice = q.correct_option), now() FROM players p LEFT JOIN answers a ON a.player_id = p.id LEFT JOIN questions q ON q.id = a.question_id WHERE p.game_id = p_game_id GROUP BY p.id ON CONFLICT (player_id) DO UPDATE SET correct_count = EXCLUDED.correct_count, updated_at = now()`.
