## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | /host gate | accept | Client gate is cosmetic (D-01a); every host API call is validated server-side by validateHostAuth. A bypassed gate still cannot mutate state. |
| T-04-02 | Information Disclosure | src/lib/host/constants.ts | mitigate | Never import `@/lib/supabase/admin` or `@/lib/auth/host` (server-only) into client constants; HOST_PASSWORD has no NEXT_PUBLIC_ prefix so it never reaches the bundle. |
| T-04-03 | Information Disclosure | useHostAuth sessionStorage | accept | Password held in sessionStorage clears on tab close (D-01); acceptable for a single-operator shared secret per RESEARCH Security Domain V3. |
| T-04-SC | Tampering | npm/shadcn installs | mitigate | shadcn CLI only pulls official Radix/shadcn packages (RESEARCH audit: all [ASSUMED] approved, well-known registries); install is an implicit checkpoint and the human-verify gate above confirms the build. |
</threat_model>
