## Spacing Scale

Multiples of 4px only. Source: Tailwind v4 default scale via `@import "tailwindcss"`.

| Token | Value | Tailwind Class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `gap-1`, `p-1` | Icon gaps, badge inner padding |
| sm | 8px | `gap-2`, `p-2` | Compact element spacing, badge px |
| md | 16px | `gap-4`, `p-4` | Default element spacing, card padding |
| lg | 24px | `gap-6`, `p-6` | Card internal padding, section gaps |
| xl | 32px | `gap-8`, `p-8` | Between major sections within a screen |
| 2xl | 48px | `py-12` | Vertical centering padding on full-screen views |
| 3xl | 64px | `py-16` | Page-level top/bottom padding on NameGate |

**Exceptions:**
- A/B button height: `min-h-[120px]` (not on scale) — touch-target requirement overrides scale; PLAY-02 compliance
- A/B button gap: `gap-4` (16px) — minimum 16px between A and B buttons per touch-spacing rule
- iOS safe-area bottom: `pb-[env(safe-area-inset-bottom)]` on all bottom-fixed/bottom-anchored elements

## Color

Source: `src/app/globals.css` `@theme` block. Use CSS custom property names as Tailwind utilities.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `ink` | `#0f0f1a` | Page background (`bg-ink`), body baseline |
| Secondary (30%) | `ink-light` | `#1a1a2e` | Card backgrounds, `.glass` surface base |
| Accent (10%) | `gold` + `gold-bright` | `#d4a843` / `#f0c060` | Reserved list below |
| State — correct reveal | `gold-bright` | `#f0c060` | Correct answer button border, text, glow shadow |

**Accent (`gold`/`gold-bright`) is reserved for exactly these elements:**
1. Locked/selected A/B button border (`border-gold`) and text glow (`text-gold-bright`)
2. Correct answer reveal: button border + shadow glow
3. Winner #1 player name
4. `canvas-confetti` particle color (implicit — library default gold/champagne)
5. `.thin-divider` rule between sections
6. QR code foreground (`fgColor="#f5e6c8"` — champagne, not gold, for readability)

**Second semantic color — wrong answer only:**
- `red-500/20` background overlay + `border-red-500/60` border on the guest's locked wrong-answer button during reveal phase
- `red-500` text on SyncStatusBadge error state
- No other red usage in guest app

### Screen 5: RevealScreen (phase = "revealed")

**Trigger:** `state.phase === "revealed"` (D-06, D-07).

**Button class derivation** (from RESEARCH.md Pattern 4):

| Condition | Classes |
|-----------|---------|
| Button is correct answer | `border-2 border-gold-bright text-gold-bright shadow-[0_0_16px_0_rgba(240,192,96,0.5)] bg-gold-muted/20` |
| Button is guest's wrong locked choice | `border-2 border-red-500/60 text-champagne bg-red-500/20` |
| Button is neither correct nor guest's pick | `border border-champagne/20 opacity-60` |

**Full cn() pattern:**
```typescript
function getRevealClass(option: "A" | "B", state: GameStateSnapshot): string {
  const isCorrect = state.correctOption === option;
  const isMyAnswer = state.myAnswer === option;

  if (isCorrect) {
    return cn(
      "w-full min-h-[120px] rounded-xl",
      "flex flex-col items-center justify-center gap-2 px-6 py-6",
      "border-2 border-gold-bright text-gold-bright",
      "bg-gold-muted/20",
      "shadow-[0_0_16px_0_rgba(240,192,96,0.5)]"
    );
  }
  if (isMyAnswer && !isCorrect) {
    return cn(
      "w-full min-h-[120px] rounded-xl",
      "flex flex-col items-center justify-center gap-2 px-6 py-6",
      "border-2 border-red-500/60 text-champagne",
      "bg-red-500/20"
    );
  }
  return cn(
    "w-full min-h-[120px] rounded-xl",
    "flex flex-col items-center justify-center gap-2 px-6 py-6",
    "border border-champagne/20 opacity-60"
  );
}
```

**Correct/wrong text indicator (icon + text — NOT color alone):**
```
// Correct answer button — add inside the button:
CheckCircle2 icon (lucide-react, size-5, text-gold-bright) + "Corect!" text
// Guest's wrong locked answer — add inside the button:
XCircle icon (lucide-react, size-5, text-red-400) + "Greșit" text
```

**A/B distribution bar (below buttons):**

## Touch Target Specification

Critical for PLAY-02 compliance on mobile. All interactive elements must meet minimum targets.

| Element | Minimum Size | Implementation |
|---------|-------------|----------------|
| A/B tap buttons | 44px height × full width | `min-h-[120px] w-full` — exceeds minimum; full-width tap zone |
| "Joacă!" submit | 44px height × full width | `h-12 w-full` (48px) |
| Name input | 44px height | `h-12` (48px) |
| Leaderboard rows | Not interactive — no minimum | — |

**Tap delay elimination:** Add `touch-action: manipulation` to all `<button>` elements. In Tailwind v4 this can be `[touch-action:manipulation]` or added to the Button CVA base class.

**Press feedback:** `active:scale-[0.97] transition-transform duration-100` on A/B buttons and submit button. Uses `transform` only — no layout-triggering properties.

## Animation Contract

Source: CONTEXT.md D-07 — No AnimatePresence in Phase 5 (deferred to Phase 7).

| Transition | Implementation | Duration |
|-----------|----------------|----------|
| Phase screen switch | Conditional render (`switch` on `state.phase`) — instant show/hide | 0ms |
| A/B button press | `active:scale-[0.97]` CSS active pseudo-class | 100ms |
| A/B button locked state | Class swap via `cn()` — no animation | instant |
| Distribution bar fill | `transition-[width] duration-300 ease-out` | 300ms |
| SyncStatusBadge appear | Conditional render — instant | 0ms |
| Confetti burst | `canvas-confetti` imperative | ~2000ms (library-controlled) |

**Reduced-motion compliance:**
```css
@media (prefers-reduced-motion: reduce) {
  .animate-pulse { animation: none; }
}
```
All transitions are `transform`/`opacity`/`width` only — no `height`, `top`, `left`.
